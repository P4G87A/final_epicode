Titolo: Sentiment Analysis di Recensioni Film (IMDB Dataset)

Di cosa si tratta: Un programma Python che analizza 50.000 recensioni di film del dataset IMDB e classifica automaticamente il sentiment (positivo/negativo) tramite tecniche di NLP.

Obiettivo: Confrontare le performance di due algoritmi di classificazione supervisionata (Naive Bayes e Logistic Regression) su un problema di sentiment analysis, valutandone accuracy, precision, recall e F1-score.

Problema che risolve: Automatizza la valutazione del sentiment in grandi volumi di testo non strutturato, un'esigenza comune in ambiti come analisi feedback clienti, monitoraggio social e moderazione contenuti.

Tecnologie: Python, pandas per il data handling, scikit-learn per vettorizzazione TF-IDF e modelli di classificazione (MultinomialNB, LogisticRegression), matplotlib per la visualizzazione (confusion matrix). Dataset: IMDB Dataset of 50K Movie Reviews (Kaggle).
